# Task 1 – Landing Page: Fieldnote Tea

**Track:** Web Development & Designing · **Level 1 · Task 1**

A static, responsive landing page for **Fieldnote**, a fictional botanical tea brand. The goal of the task is to practise core HTML and CSS layout skills: structure, spacing, typography and responsive design.

## Features

- Sticky navigation bar with links to *Our blend*, *The ritual* and *Kind words*
- Hero section with headline, subheadline and call-to-action buttons
- Multiple content sections: featured tea blends, brand story ("The ritual") and a customer testimonial
- Footer with contact and social links (placeholder links)
- Consistent colour palette and a two-font pairing (Playfair Display for headings, DM Sans for body text)
- Responsive layout built with CSS Flexbox and CSS Grid, with breakpoints for tablet and mobile
- Smooth scrolling between sections
- `prefers-reduced-motion` support for accessibility
- Intentional `box-sizing`, padding and margins so no elements overlap

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Google Fonts
- Images from Unsplash
